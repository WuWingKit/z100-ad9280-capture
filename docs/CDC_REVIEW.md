# CDC 报告审阅

依据本版最终 `hardware/cdc_routed.rpt`，保留工具原始报告，不隐藏或降低警告。

本版将跨域前的 busy / waiting_dma 等组合状态先在 ADC 域寄存，消除了这两个自定义状态路径的 CDC-10。剩余诊断：

| 项目 | 路径/原因 | 本版处理与约束 |
|---|---|---|
| CDC-10，2 项 Critical | PS 复位与软件复位组合后，送 ADC 域复位同步链及 FIFO IP 复位入口 | 这是异步复位断言路径；自定义逻辑各域用两级链同步释放，FIFO 使用厂商内部复位同步/拉伸。PS 同时复位 DMA 并等待 100 ms 后才允许 START。测量中复位视为整帧作废，不能保留半帧继续采集。 |
| CDC-13，1 项 Critical | FIFO Generator 内部 FIFO36E1 的 RST 引脚，由厂商写侧上电复位同步电路驱动 | 位于厂商原语及复位实现内部，未绕过厂商同步链；实际独立时钟 FIFO 模型的复位、读写和恢复测试已通过。 |
| CDC-6，1 项 Warning | length → nmeta/nsync，ADC→AXI 的多位帧长总线 | length 每次任务锁存，整个任务保持不变；在 PREP 及 CORDIC 等待期间已经稳定，远早于第一个 FIFO 字。AXI 侧不允许在帧中途修改帧长。 |

配置 K/N/delay/amp 总线在 PS 写完后保持 1 ms，再通过 START toggle 通知 ADC 域，直到 DMA 完成 ACK 前都不改变。两级同步本身不能保证任意多位变化的原子性；本版依赖这个稳定总线协议。任何后续驱动都必须遵守它。

状态中的 count/state 是诊断值，可能在跨域变化过程中暂时不一致；软件只在帧完成、DMA 完成后再等待 10 μs 读取计数。busy、frame_done 等独立控制状态在源域寄存后再同步。

仿真能检查协议与数据完整性，不能模拟亚稳态概率，也不能替代真实复位、时钟丢失/恢复及长期运行测试。当前结论是单帧控制协议下的设计审阅，未作任意异步事件下的完整 CDC 签核。
