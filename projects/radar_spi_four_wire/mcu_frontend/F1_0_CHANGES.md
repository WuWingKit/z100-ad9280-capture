# f1_0 变更摘要

- 固件版本改为 `f1_0` / 1.0.0，Keil 目标和构建产物改名为 `firmware_f1_0`。
- 删除原查询任务，只保留 UART0 `0x29` FMCW 带宽修改和 `0x2A` 帧周期修改；无 UART TX 回包。
- 删除槽位模型、槽位/参数 Flash 持久化、运行时 Flash BSP 业务代码。
- 删除多帧/多 chirp 平均后处理、FFT/相位/绝对距离/静态杂波/峰值等算法应用与算法包引用。
- 固定 19 波束循环：-45° 到 +45°，5° 步进；相位表来自原 73 波束标定表每隔 4 项抽取。
- 保留原 ADC DMA 采集路径，并将波束切换严格固定为：RF on + ADC DMA → 100 us → TX PSR → RX PSR → 主循环轮询 ADC DMA 完成 → RF off → TX LOAD → RX LOAD；ADC DMA DONE 中断不再执行任何业务。
- RAM 改为 A/B 两个 48 KiB 原始 ADC 帧缓冲区，地址 `0x20008000` 和 `0x20014000`。
- 新增 SPI0 原始数据流；SPI0 16 bit / 12.5 MHz；P0/TX0 作为低有效 `/CS`，P4 原 Flash CS 固定高。
- SPI 输出源先预配置，ADC 启动后立即触发 SPI 输出；上一帧发送与下一帧采集 ping-pong 并行。
- 每轮完成条件由“结果 FIFO 入队”改为“SPI 发送完成”；之后等待默认 50 ms 周期边界。
- 删除旧 V2.6/V2.7 协议/变更文档和旧构建输出，避免与 f1_0 行为混淆。
